# Exercise 01

## Python version

Python 3.12.16

## How to run the notebook

1. Open Miniforge Prompt and go to the `2026-research-methods` repository folder.
2. Activate the course environment:

   ```text
   conda activate research-methods
   ```

3. Start JupyterLab:

   ```text
   jupyter lab
   ```

4. In JupyterLab, open `practice/Zevakinaite/assignment-01/exercise_01.ipynb`.
5. Choose **Kernel → Restart Kernel and Run All Cells** to run the notebook from beginning to end.
