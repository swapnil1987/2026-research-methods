## How to open and run the notebook

1. Open **Miniforge Prompt** (Windows) or **Terminal** (macOS/Linux).
2. Go to the folder that contains `exercise_01.ipynb`:
   `cd /d "FULL FOLDER ADDRESS"` (Windows) or `cd "FULL FOLDER ADDRESS"` (macOS/Linux).
3. Activate the environment: `conda activate research-methods`
4. Start JupyterLab: `jupyter lab`
5. Open `exercise_01.ipynb` and select the Python 3 kernel.
6. Choose **Kernel → Restart Kernel and Run All Cells…**.

The notebook uses only built-in Python and the `math` module. It needs no data files and
no internet access. The last code cell prints `All assertions passed.`
