# Final practical — Who gets the carbon dividend?

## Python version

Python 3.12.16 with pandas 3.1.0, plotnine 0.15.9 and numpy 2.5.4
(`research-methods` conda environment).

## How to run

1. Open `final_practical.ipynb` in JupyterLab with the `research-methods` environment.
2. Keep `households.csv` beside the notebook. If it is not there, the notebook looks one folder above.
3. Restart the kernel and run all cells.

The notebook checks both plans, makes the table and figure, and compares different payment splits. It also checks the per-person result and the earlier double-payment idea.
