# Coding Assignment 1 — Household support

## Python version

Python 3.12.16 (tested with the notebook kernel).

## How to open and run

1. Open `exercise_01.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. Select a Python 3 kernel (the notebook was written with the `research-methods` kernel).
3. Restart the kernel and run all cells in order (`Kernel -> Restart & Run All`, or `Run All` in VS Code).

The notebook prints one report line per household, the totals and averages, the sorted shares, the A01 counterfactual, and finally `All assertions passed.` If that last line is missing, one of the checks failed.
