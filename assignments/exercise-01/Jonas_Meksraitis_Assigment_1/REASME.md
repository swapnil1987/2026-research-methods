# Coding Assignment 1 — Household Support

**Course:** Research Methods 2026

**Assignment:** Household support: implement, inspect, and verify

## Files

- `exercise_01.ipynb` — Python solutions, household calculations, explanations, and verification tests.
- `README.md` — Instructions for reproducing the assignment and AI-use disclosure.

## Python environment

- Python version: `3.12.16`
- Environment: Conda (`research-methods`)
- Interface: JupyterLab

The solution uses Python built-in functions and the standard-library `math` module. No external data files or additional analytical libraries are required.

## Instructions

1. Activate the Conda environment using `conda activate research-methods`.
2. Launch JupyterLab using `jupyter lab`.
3. Open `exercise_01.ipynb`.
4. Select **Kernel → Restart Kernel and Run All Cells**.
5. Review the resulting calculations, reports, and assertions.

The notebook is designed to execute sequentially without manual input.
