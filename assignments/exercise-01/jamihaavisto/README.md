# Research Methods: Coding Assignment 1

## Python version

The course environment specifies Python 3.12. The notebook's kernel metadata records Python 3.12.16.

## Open and run the notebook

From the course project root, activate the course environment and start JupyterLab:

```bash
conda activate research-methods
cd codes/exercise-1
jupyter lab
```

In JupyterLab, open `exercise_01.ipynb`. To reproduce the results from a clean session, choose **Kernel → Restart Kernel and Run All Cells** and let all cells finish.
