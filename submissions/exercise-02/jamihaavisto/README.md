## Data

Create a local `data` folder beside the notebook. Download the [zipped flights data](https://raw.githubusercontent.com/machow/nycflights13-py/1d40369400d77379a78641afd119fc302a5a9659/nycflights13/data/flights.csv.zip) and keep it named `flights.csv.zip`. Download the [airline lookup](https://raw.githubusercontent.com/machow/nycflights13-py/1d40369400d77379a78641afd119fc302a5a9659/nycflights13/data/airlines.csv) as `airlines.csv`. Keep these raw files on your computer; do not include them in the pull request.

## Run

From the course repository root, start Miniforge Prompt and run:

```text
conda activate research-methods
cd submissions/exercise-02/jamihaavisto
jupyter lab
```

Open `exercise_02.ipynb` in JupyterLab, restart the kernel, and run all cells in order. The notebook includes the draft and final figure versions; the final figure is also provided separately as `figure.png`.
